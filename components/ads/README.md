# Ad Components

Reusable HTML ad slot snippets for use in any project.

## Status

⚠️ **These are placeholders only.** Do not activate until you have:
1. A real Google AdSense publisher ID (`ca-pub-XXXXXXXXXXXXXXXX`)
2. AdSense approval for the domain/subdomain
3. An active `ads.txt` file on the domain root

## How to use

1. Copy the relevant snippet from a component file below.
2. Paste it into your project HTML at the desired location.
3. Replace `ca-pub-XXXXXXXXXXXXXXXX` with your real publisher ID.
4. Replace `XXXXXXXXXX` with the real ad unit ID from your AdSense dashboard.
5. Remove the `<!-- PLACEHOLDER -->` comment.

## Files

| File               | Placement                              |
|--------------------|----------------------------------------|
| `header-ad.html`   | Below the header / above the fold      |
| `content-ad.html`  | Mid-article or between content blocks  |
| `sidebar-ad.html`  | Sidebar (desktop only)                 |
| `footer-ad.html`   | Above the footer                       |

## AdSense policies reminder

- Never ask users to click ads.
- Never place ads near clickable elements in a misleading way.
- Never artificially inflate impressions.
- Review [AdSense policies](https://support.google.com/adsense/answer/48182) before going live.
